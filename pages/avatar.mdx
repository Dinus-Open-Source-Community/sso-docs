# Avatar — `POST /api/avatar`

Upload foto profil user. Avatar disimpan di object storage (MinIO) SSO;
database hanya menyimpan URL-nya (`avatar_url`).

Base URL: `https://sso.doscom.org` (development: `http://localhost:8080`)

## POST /api/avatar 🔒

**Request** (`multipart/form-data`)

| Field | Wajib | Keterangan |
|-------|-------|-----------|
| `avatar` | Ya | File gambar, maks **5 MB**, semua format gambar |

Header: `Authorization: Bearer TOKEN_JWT` (JWT user dari SSO — lihat [Auth API](/auth-api)).

**Response** `200 OK` — `data` berisi objek user lengkap dengan `avatar_url` baru:

```json
{
  "status": true,
  "message": "avatar uploaded",
  "data": {
    "id": 4,
    "name": "Budi Santoso",
    "email": "budi@doscom.org",
    "avatar_url": "https://cdn.doscom.org/avatars/4-abc123.png",
    "email_verified": true,
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

**Error**:

| Code | Penyebab |
|------|----------|
| `400` | Field `avatar` kosong / bukan file |
| `401` | Token JWT tidak valid / expired |
| `413` | File lebih dari 5 MB |

<Callout type="info">
  `avatar_url` yang baru juga otomatis muncul di:
  - `GET /userinfo` → field `avatar_url` (scope `profile`)
  - klaim `picture` di `id_token` (scope `profile`)
</Callout>

<Tab>

```go
import (
    "bytes"
    "io"
    "mime/multipart"
    "net/http"
    "os"
    "path/filepath"
)

func uploadAvatar(token, filePath string) error {
    var buf bytes.Buffer
    w := multipart.NewWriter(&buf)

    fw, err := w.CreateFormFile("avatar", filepath.Base(filePath))
    if err != nil {
        return err
    }
    f, err := os.Open(filePath)
    if err != nil {
        return err
    }
    defer f.Close()
    if _, err := io.Copy(fw, f); err != nil {
        return err
    }
    w.Close()

    req, err := http.NewRequest("POST",
        "https://sso.doscom.org/api/avatar", &buf)
    if err != nil {
        return err
    }
    req.Header.Set("Authorization", "Bearer "+token)
    req.Header.Set("Content-Type", w.FormDataContentType())

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return err
    }
    defer resp.Body.Close()
    return nil
}
```

```js
// Browser (FormData) atau Node.js 18+ (fetch + FormData/Blob)
const form = new FormData()
form.append('avatar', fileInput.files[0])

const res = await fetch('https://sso.doscom.org/api/avatar', {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}` },
  body: form,
})
const body = await res.json() // data.avatar_url = URL baru
```

<Tab>

```php
$res = $client->post('/api/avatar', [
    'headers' => ['Authorization' => 'Bearer ' . $token],
    'multipart' => [
        [
            'name'     => 'avatar',
            'contents' => fopen('/path/ke/foto-profil.png', 'r'),
            'filename' => 'foto-profil.png',
        ],
    ],
]);
$body = json_decode($res->getBody(), true); // $body['data']['avatar_url']
```

<Tab>

```python
import requests

with open('foto-profil.png', 'rb') as f:
    r = requests.post(
        'https://sso.doscom.org/api/avatar',
        headers={'Authorization': f'Bearer {token}'},
        files={'avatar': ('foto-profil.png', f, 'image/png')},
    )
avatar_url = r.json()['data']['avatar_url']
```

<Callout type="warning">
  Endpoint `/api/avatar` khusus untuk user biasa mengubah avatar **sendiri**
  (token `kind: user`). Endpoint admin (`/api/users/*`) tidak didokumentasikan di sini.
</Callout>
