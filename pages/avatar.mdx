# Avatar — upload foto profil

Upload foto profil user. Avatar disimpan di object storage (MinIO) SSO;
database hanya menyimpan URL-nya (`avatar_url`).

Base URL: `https://sso.doscom.org` (development: `http://localhost:8080`)

<Callout type="warning">
  Endpoint JSON lama `POST /api/avatar` sudah **dihapus**. Upload avatar kini
  hanya lewat **Portal Akun** (dashboard "Akun doscom") — bukan API
  server-to-server.
</Callout>

## POST /account/avatar 🔒 (Portal Akun)

Halaman: `https://sso.doscom.org/` (login dulu → dashboard → form foto profil).

**Request** (`multipart/form-data`, browser form — auth via cookie session
`session_id` + `active_user_id`, bukan Bearer token):

| Field | Wajib | Keterangan |
|-------|-------|-----------|
| `avatar` | Ya | File gambar, maks **5 MB**. Format didukung: jpeg, png, gif, webp, bmp, tiff, ico, svg, avif, heic/heif (terdeteksi dari isi file, bukan sekadar ekstensi) |

**Response**: redirect kembali ke `/` (pola PRG) dengan flash message
"Foto profil berhasil diperbarui." — bukan JSON.

**Error** (ditampilkan sebagai banner di dashboard):

| Penyebab |
|------|
| Field `avatar` kosong / bukan file gambar |
| File lebih dari 5 MB |
| MinIO belum tersedia (`Upload foto profil belum tersedia. Pastikan MinIO berjalan.`) |

<Callout type="info">
  `avatar_url` yang baru otomatis muncul di:
  - `GET /userinfo` → field `avatar_url`
  - klaim `picture` di `id_token` (scope `profile`)
  - daftar akun di account chooser (`/authorize` dan Portal Akun)
</Callout>

## Untuk developer aplikasi pihak ketiga

Jangan implementasikan upload avatar sendiri — arahkan user ke Portal Akun SSO
untuk ganti foto. Yang perlu aplikasimu lakukan hanyalah **membaca**
`avatar_url` terbaru:

- Setelah login OAuth: `GET /userinfo` → `avatar_url` (lihat
  [Endpoint Referensi](/endpoints)).
- Dari `id_token`: klaim `picture` (scope `profile`) — verifikasi via JWKS
  seperti biasa.
- Sinkronisasi berkala tidak diperlukan — `avatar_url` bersifat stabil
  (path `avatars/YYYYMMDD<userID>.<ext>` di bucket publik MinIO).

> Contoh membaca `avatar_url` dari `/userinfo` dalam 8 bahasa: lihat panduan
> [Integrasi](/integration/go) masing-masing bahasa (bagian callback).
