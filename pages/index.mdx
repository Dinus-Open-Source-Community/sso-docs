# DOSCOM SSO — Dokumentasi Integrasi

**DOSCOM SSO** adalah server Single Sign-On (SSO) berbasis protokol standar **OAuth 2.0** dan **OpenID Connect (OIDC)**.
Artinya: aplikasi kamu bisa menggunakan tombol *"Login dengan Akun DOSCOM"* tanpa tahu cara enkripsi password — cukup komunikasi HTTP biasa.

> **Tidak terikat bahasa pemrograman.** Karena semua komunikasi via HTTP + JWT standar,
> kamu bisa integrasi dari Go, Node.js, PHP, Python, Java, atau bahasa apapun.
