# Integrasi Node.js

Gunakan library `openid-client` — implementasi OAuth2/OIDC terlengkap untuk Node.js.
Contoh berikut pakai Express, tapi pola yang sama berlaku untuk framework apapun.

## Instalasi

```bash
npm install openid-client express-session
```

## Setup

```js
// sso.js
const { Issuer } = require('openid-client')

let ssoClient

async function getSSOClient() {
  if (ssoClient) return ssoClient

  // Auto-discovery dari OIDC metadata endpoint
  const issuer = await Issuer.discover('https://sso.doscom.org')

  ssoClient = new issuer.Client({
    client_id: process.env.SSO_CLIENT_ID,
    client_secret: process.env.SSO_CLIENT_SECRET, // kosong untuk public client
    redirect_uris: ['https://appkamu.com/callback'],
    response_types: ['code'],
  })

  return ssoClient
}

module.exports = { getSSOClient }
```

## Handler Login (Express)

```js
const { generators } = require('openid-client')

app.get('/login', async (req, res) => {
  const client = await getSSOClient()

  // PKCE (wajib untuk public client, direkomendasikan untuk semua)
  const codeVerifier = generators.codeVerifier()
  const codeChallenge = generators.codeChallenge(codeVerifier)
  const state = generators.state()

  // Simpan di session
  req.session.codeVerifier = codeVerifier
  req.session.state = state

  const authUrl = client.authorizationUrl({
    scope: 'openid profile email',
    state,
    code_challenge: codeChallenge,
    code_challenge_method: 'S256',
  })

  res.redirect(authUrl)
})
```

## Handler Callback (Express)

```js
app.get('/callback', async (req, res) => {
  const client = await getSSOClient()

  const params = client.callbackParams(req)

  // Verifikasi state + tukar code → token (termasuk verifikasi id_token otomatis)
  const tokenSet = await client.callback(
    'https://appkamu.com/callback',
    params,
    {
      state: req.session.state,
      code_verifier: req.session.codeVerifier,
    }
  )

  // Klaim id_token (sudah diverifikasi: signature, iss, aud, exp)
  const claims = tokenSet.claims() // sub, name, email, picture

  // Ambil profil dari /userinfo (profil lengkap user)
  const userinfo = await client.userinfo(tokenSet.access_token)

  // Simpan ke session
  req.session.user = { id: userinfo.id, email: userinfo.email, name: userinfo.name }
  req.session.avatarUrl = userinfo.avatar_url
  req.session.accessToken = tokenSet.access_token
  req.session.refreshToken = tokenSet.refresh_token

  res.redirect('/dashboard')
})
```

<Callout type="info">
  Klaim `tokenSet.claims()` berasal dari **id_token** (`sub`, `picture`, ...)
  dan mengikuti scope yang diminta. `client.userinfo()` memanggil endpoint
  `/userinfo` yang formatnya berbeda dan **selalu** mengembalikan profil
  lengkap: `{ id, name, email, avatar_url, bind, email_verified, created_at }`
  (`bind` = array `[{client_id, name}]`, otomatis terisi saat login sukses).
</Callout>

## Refresh Token

```js
app.use(async (req, res, next) => {
  const client = await getSSOClient()

  if (req.session.accessToken && isExpired(req.session.accessToken)) {
    // SSO me-rotate refresh token — simpan token baru!
    const tokenSet = await client.refresh(req.session.refreshToken)
    req.session.accessToken  = tokenSet.access_token
    req.session.refreshToken = tokenSet.refresh_token
  }

  next()
})
```

## Logout & Revoke

```js
app.post('/logout', async (req, res) => {
  const client = await getSSOClient()

  // Cabut refresh token di SSO (best-effort, RFC 7009)
  await client.revoke(req.session.refreshToken).catch(() => {})

  req.session.destroy(() => res.redirect('/'))
})
```

## Bind Akun & Status Bind

Pola acuan: `DummyWebSSO` (`sso.js` + `server.js`). Selain "Login with
Doscom", tautkan akun lokal via [Auth API](/auth-api):

```js
// 1. Minta URL form bind SSO
const res = await fetch(`${SSO}/api/auth/bind`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name, email,
    client_id: process.env.SSO_CLIENT_ID,
    return_url: `${process.env.APP_BASE_URL}/profile`,
  }),
})
const { data } = await res.json() // data.url -> tampilkan sebagai link

// 2. User isi form / konfirmasi di SSO -> SSO simpan niat bind + kirim OTP
//    bind_account ke email -> redirect /api/auth/bind/otp?token=<PENDING>
//    -> user input 6 digit kode (bisa kirim ulang via resend=1).
//    OTP benar -> bind dieksekusi -> redirect {return_url}?bind_token=<JWT>.

// 3. Setelah redirect {return_url}?bind_token=<JWT>: verifikasi RS256 via
//    {SSO}/.well-known/jwks.json — cek iss, aud == client_id sendiri,
//    event == 'account.bind', exp (±5 mnt) — lalu tautkan akun lokal.

// 3. Sinkronisasi: GET {SSO}/api/auth/binding/status?email=&client_id=
//    HANYA untuk akun ter-bind lokal. bound:false/404 -> hapus kaitan lokal;
//    429/jaringan -> pakai cache lokal.
//    Catatan: DummyWebSSO belum mendukung langkah OTP di atas.
```

## Auth API & Avatar

Untuk menautkan akun lokal lihat **[Auth API — Bind](/auth-api)**.
Upload avatar via API (`POST /api/avatar`) sudah **dihapus** — user mengganti
foto lewat [Portal Akun](/account-portal); aplikasimu cukup membaca
`avatar_url` terbaru dari `/userinfo`:

```js
// Baca avatar terbaru (bukan upload)
const userinfo = await client.userinfo(tokenSet.access_token)
const avatarUrl = userinfo.avatar_url
```
