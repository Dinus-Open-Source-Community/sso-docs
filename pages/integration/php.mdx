# Integrasi PHP (Laravel / Vanilla)

Gunakan library `league/oauth2-client` yang sudah menjadi standar di ekosistem PHP.

## Instalasi

```bash
composer require league/oauth2-client
composer require guzzlehttp/guzzle  # untuk Auth API & Avatar
```

## Setup Provider

```php
<?php
// config/sso.php atau langsung di controller

use League\OAuth2\Client\Provider\GenericProvider;

$provider = new GenericProvider([
    'clientId'                => env('SSO_CLIENT_ID'),
    'clientSecret'            => env('SSO_CLIENT_SECRET'), // '' untuk public client
    'redirectUri'             => 'https://appkamu.com/callback',
    'urlAuthorize'            => 'https://sso.doscom.org/authorize',
    'urlAccessToken'          => 'https://sso.doscom.org/token',
    'urlResourceOwnerDetails' => 'https://sso.doscom.org/userinfo',
]);
```

## Handler Login

```php
<?php
// routes/web.php atau controller

Route::get('/login/sso', function () use ($provider) {
    // State otomatis di-generate library
    $authUrl = $provider->getAuthorizationUrl([
        'scope' => ['openid', 'profile', 'email'],
    ]);

    // Simpan state di session untuk verifikasi CSRF
    session(['oauth2state' => $provider->getState()]);

    return redirect($authUrl);
});
```

<Callout type="info">
  `league/oauth2-client` **v2.7+** mendukung PKCE (`$provider->enablePkce()` sebelum
  `getAuthorizationUrl` — verifier disimpan otomatis di session).
  Untuk **public client** (tanpa secret), PKCE wajib — aktifkan fitur ini.
  Untuk **confidential client** (ada secret), PKCE opsional.
</Callout>

## Handler Callback

```php
Route::get('/callback', function (Request $request) use ($provider) {
    // Verifikasi state (CSRF)
    if ($request->state !== session('oauth2state')) {
        abort(400, 'State mismatch — kemungkinan CSRF attack');
    }

    // Tukar code dengan token
    $token = $provider->getAccessToken('authorization_code', [
        'code' => $request->code,
    ]);

    // Ambil data user dari /userinfo
    // Response: id, name, email, avatar_url, bind, email_verified, created_at
    // (bind = [{client_id, name}], otomatis terisi saat login sukses)
    $user = $provider->getResourceOwner($token);
    $userArray = $user->toArray();

    // Simpan ke session
    session([
        'user'          => $userArray,
        'access_token'  => $token->getToken(),
        'refresh_token' => $token->getRefreshToken(),
        'expires'       => $token->getExpires(),
    ]);

    return redirect('/dashboard');
});
```

## Refresh Token

```php
$existingToken = new \League\OAuth2\Client\Token\AccessToken([
    'access_token'  => session('access_token'),
    'refresh_token' => session('refresh_token'),
    'expires'       => session('expires'),
]);

if ($existingToken->hasExpired()) {
    // SSO me-rotate refresh token — simpan token baru!
    $newToken = $provider->getAccessToken('refresh_token', [
        'refresh_token' => $existingToken->getRefreshToken(),
    ]);

    session([
        'access_token'  => $newToken->getToken(),
        'refresh_token' => $newToken->getRefreshToken(),
        'expires'       => $newToken->getExpires(),
    ]);
}
```

## Verifikasi `id_token` (JWT)

`league/oauth2-client` tidak verifikasi `id_token` secara otomatis.
Untuk verifikasi, gunakan `firebase/php-jwt`:

```bash
composer require firebase/php-jwt
```

```php
use Firebase\JWT\JWT;
use Firebase\JWT\JWK;

// Ambil JWKS dari SSO
$jwks = json_decode(file_get_contents('https://sso.doscom.org/.well-known/jwks.json'), true);
$keys = JWK::parseKeySet($jwks);

// Verifikasi signature RS256 (cek iss/aud/exp sesuai kebutuhan aplikasi)
$decoded = JWT::decode($idToken, $keys);
// $decoded->sub, $decoded->email, $decoded->picture, dll.
```

## Bind Akun & Status Bind

Pola acuan: `DummyWebSSO` (`sso.js`). Selain "Login with Doscom", tautkan akun
lokal via [Auth API](/auth-api): `POST {SSO}/api/auth/bind` (`name`, `email`,
`client_id`, `return_url`) → tampilkan `data.url` ke user → setelah redirect
`{return_url}?bind_token=<JWT>`, verifikasi RS256 via JWKS (`iss`, `aud` =
client_id sendiri, `event = account.bind`, `exp` ±5 mnt) → tautkan akun lokal.
Sinkronisasi via `GET {SSO}/api/auth/binding/status` **hanya** untuk akun
ter-bind lokal (akun lokal jangan hit; `bound:false`/404 → hapus kaitan lokal).

Sejak update terbaru, submit form/konfirmasi **tidak langsung** mengeksekusi
bind — SSO menyimpan niat bind + mengirim kode OTP 6 digit
(`purpose = bind_account`) ke email user, lalu redirect ke
`/api/auth/bind/otp?token=<PENDING>`. Bind dieksekusi dan `bind_token`
di-redirect ke `return_url` hanya setelah OTP benar (bisa kirim ulang via
`resend=1`). `DummyWebSSO` belum mendukung langkah OTP ini — lihat alur
lengkap di [Auth API — Bind](/auth-api).

## Auth API & Avatar

Untuk menautkan akun lokal lihat **[Auth API — Bind](/auth-api)**.
Upload avatar via API (`POST /api/avatar`) sudah **dihapus** — user mengganti
foto lewat [Portal Akun](/account-portal) (`POST /account/avatar`);
aplikasimu cukup membaca `avatar_url` terbaru dari `/userinfo`:

```php
$userArray = $user->toArray();
$avatarUrl = $userArray['avatar_url'] ?? null; // baca, bukan upload
```
