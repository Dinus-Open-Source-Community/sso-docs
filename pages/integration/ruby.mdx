# Integrasi Ruby (Rails / Sinatra)

Gunakan gem `oauth2` — client OAuth2 standar di ekosistem Ruby. Contoh berikut
framework-agnostic, bisa dipasang di Rails, Sinatra, atau Rack app apapun.

## Instalasi

```ruby
# Gemfile
gem 'oauth2'
gem 'jwt'   # untuk verifikasi id_token
gem 'faraday-multipart'
```

## Setup Client

```ruby
require 'oauth2'

client = OAuth2::Client.new(
  ENV['SSO_CLIENT_ID'],
  ENV['SSO_CLIENT_SECRET'], # nil untuk public client
  site:          'https://sso.doscom.org',
  authorize_url: '/authorize',
  token_url:     '/token',
)
```

## Handler Login

```ruby
require 'securerandom'

get '/login' do
  session[:oauth_state]    = SecureRandom.urlsafe_base64(16)
  session[:pkce_verifier]  = SecureRandom.urlsafe_base64(32)

  redirect client.auth_code.authorize_url(
    redirect_uri:  'https://appkamu.com/callback',
    scope:         'openid profile email',
    state:         session[:oauth_state],
    code_challenge:        pkce_challenge(session[:pkce_verifier]),
    code_challenge_method: 'S256',
  )
end

# code_challenge = BASE64URL(SHA256(verifier))
def pkce_challenge(verifier)
  Base64.urlsafe_encode64(Digest::SHA256.digest(verifier), padding: false)
end
```

## Handler Callback

```ruby
get '/callback' do
  # Verifikasi state (CSRF)
  halt 400, 'state mismatch' unless params[:state] == session[:oauth_state]
  halt 401, "SSO menolak: #{params[:error]}" if params[:error]

  # Tukar code → token
  token = client.auth_code.get_token(
    params[:code],
    redirect_uri: 'https://appkamu.com/callback',
    code_verifier: session[:pkce_verifier], # nil untuk confidential tanpa PKCE
  )

  # Profil user dari /userinfo (profil lengkap user)
  userinfo = token.get('/userinfo').parsed

  # Simpan session
  session[:user]          = userinfo
  session[:access_token]  = token.token
  session[:refresh_token] = token.refresh_token

  redirect '/dashboard'
end
```

## Verifikasi `id_token`

```ruby
require 'jwt'

jwks = JSON.parse(Faraday.get('https://sso.doscom.org/.well-known/jwks.json').body)

decoded = JWT.decode(id_token, nil, true, {
  algorithm: 'RS256',
  jwks:      { keys: jwks['keys'] },
})[0]
# decoded['sub'], decoded['email'], decoded['picture']
```

<Callout type="info">
  Gem `jwt` mendukung JWKS langsung — signature diverifikasi otomatis.
  Cek tambahan sesuai kebutuhan: `iss` = `https://sso.doscom.org`,
  `aud` = client_id kamu.
</Callout>

## Refresh Token

```ruby
token = OAuth2::AccessToken.from_hash(client, {
  'refresh_token' => session[:refresh_token],
})

# SSO me-rotate refresh token — simpan token baru!
new_token = token.refresh!
session[:access_token]  = new_token.token
session[:refresh_token] = new_token.refresh_token
```

## Logout & Revoke

```ruby
post '/logout' do
  # Cabut refresh token di SSO (best-effort)
  Faraday.post('https://sso.doscom.org/revoke',
    { token: session[:refresh_token], client_id: ENV['SSO_CLIENT_ID'] },
    { 'Content-Type' => 'application/x-www-form-urlencoded' }
  ) rescue nil

  session.clear
  redirect '/'
end
```

## Bind Akun & Status Bind

Pola acuan: `DummyWebSSO` (`sso.js`). Selain "Login with Doscom", tautkan akun
lokal via [Auth API](/auth-api): `POST {SSO}/api/auth/bind` (`name`, `email`,
`client_id`, `return_url`) → tampilkan `data.url` ke user → setelah redirect
`{return_url}?bind_token=<JWT>`, verifikasi RS256 via JWKS (`iss`, `aud` =
client_id sendiri, `event = account.bind`, `exp` ±5 mnt) → tautkan akun lokal.
Sinkronisasi via `GET {SSO}/api/auth/binding/status` **hanya** untuk akun
ter-bind lokal.

Sejak update terbaru, submit form/konfirmasi **tidak langsung** mengeksekusi
bind — SSO menyimpan niat bind + mengirim kode OTP 6 digit
(`purpose = bind_account`) ke email user, lalu redirect ke
`/api/auth/bind/otp?token=<PENDING>`. Bind dieksekusi dan `bind_token`
di-redirect ke `return_url` hanya setelah OTP benar (bisa kirim ulang via
`resend=1`). `DummyWebSSO` belum mendukung langkah OTP ini — lihat alur
lengkap di [Auth API — Bind](/auth-api).

## Auth API & Avatar

Lihat **[Auth API — Bind](/auth-api)**. Upload avatar via API
(`POST /api/avatar`) sudah **dihapus** — user mengganti foto lewat
[Portal Akun](/account-portal); aplikasimu cukup membaca `avatar_url` terbaru
dari `/userinfo`:

```ruby
userinfo = token.get('/userinfo').parsed
avatar_url = userinfo['avatar_url'] # baca, bukan upload
# userinfo['bind'] = [{'client_id' => ..., 'name' => ...}]
```
