# Integrasi Java

Contoh berikut framework-agnostic — hanya memakai `java.net.http.HttpClient`
(JDK 11+), tanpa dependency tambahan. Cocok untuk Spring Boot, Quarkus, atau
servlet app apapun.

## Setup Client

```java
import java.net.http.HttpClient;

public final class SsoConfig {
    public static final String BASE_URL   = "https://sso.doscom.org";
    public static final String CLIENT_ID  = System.getenv("SSO_CLIENT_ID");
    public static final String CLIENT_SECRET = System.getenv("SSO_CLIENT_SECRET");
    public static final String REDIRECT_URI = "https://appkamu.com/callback";

    public static final HttpClient HTTP = HttpClient.newHttpClient();
}
```

## Handler Login

```java
import java.net.URI;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.SecureRandom;
import java.util.Base64;

// Bangkitkan PKCE (S256) + state, simpan di session/cookie, lalu redirect
public String authorizeUrl(String state, String codeVerifier) throws Exception {
    // code_challenge = BASE64URL(SHA256(code_verifier))
    byte[] digest = MessageDigest.getInstance("SHA-256")
        .digest(codeVerifier.getBytes(StandardCharsets.US_ASCII));
    String challenge = Base64.getUrlEncoder().withoutPadding().encodeToString(digest);

    return SsoConfig.BASE_URL + "/authorize"
        + "?client_id=" + enc(SsoConfig.CLIENT_ID)
        + "&redirect_uri=" + enc(SsoConfig.REDIRECT_URI)
        + "&response_type=code"
        + "&scope=" + enc("openid profile email")
        + "&state=" + enc(state)
        + "&code_challenge=" + enc(challenge)
        + "&code_challenge_method=S256";
}

// Helper: verifier & state acak
public static String randomToken() {
    byte[] b = new byte[32];
    new SecureRandom().nextBytes(b);
    return Base64.getUrlEncoder().withoutPadding().encodeToString(b);
}

static String enc(String s) {
    return URLEncoder.encode(s, StandardCharsets.UTF_8);
}
```

## Handler Callback — Tukar Code

```java
import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;

// POST /token (application/x-www-form-urlencoded)
public JsonNode exchangeCode(String code, String codeVerifier) throws Exception {
    String form = "grant_type=authorization_code"
        + "&code=" + enc(code)
        + "&redirect_uri=" + enc(SsoConfig.REDIRECT_URI)
        + "&client_id=" + enc(SsoConfig.CLIENT_ID)
        + (SsoConfig.CLIENT_SECRET.isEmpty() ? "" : "&client_secret=" + enc(SsoConfig.CLIENT_SECRET))
        + "&code_verifier=" + enc(codeVerifier);

    HttpRequest req = HttpRequest.newBuilder(URI.create(SsoConfig.BASE_URL + "/token"))
        .header("Content-Type", "application/x-www-form-urlencoded")
        .POST(HttpRequest.BodyPublishers.ofString(form))
        .build();

    HttpResponse<String> resp = SsoConfig.HTTP.send(req, HttpResponse.BodyHandlers.ofString());
    if (resp.statusCode() != 200) {
        throw new IllegalStateException("/token -> " + resp.statusCode() + ": " + resp.body());
    }
    return new ObjectMapper().readTree(resp.body());
    // access_token, refresh_token, id_token, expires_in
}
```

## Ambil Profil dari /userinfo

```java
public JsonNode userinfo(String accessToken) throws Exception {
    HttpRequest req = HttpRequest.newBuilder(URI.create(SsoConfig.BASE_URL + "/userinfo"))
        .header("Authorization", "Bearer " + accessToken)
        .GET().build();

    HttpResponse<String> resp = SsoConfig.HTTP.send(req, HttpResponse.BodyHandlers.ofString());
    return new ObjectMapper().readTree(resp.body());
    // id, name, email, avatar_url, bind, email_verified, created_at
    // (bind = [{client_id, name}], otomatis terisi saat login sukses)
}
```

<Callout type="info">
  Verifikasi `id_token` secara lokal: unduh JWKS dari `/.well-known/jwks.json` dan
  verifikasi signature RS256 dengan library seperti `com.auth0:java-jwt` atau
  `com.nimbusds:nimbus-jose-jwt` (cek `iss` = base URL SSO, `aud` = client_id, `exp`).
</Callout>

## Bind Akun & Status Bind

Pola acuan: `DummyWebSSO` (`sso.js`). Selain "Login with Doscom", tautkan akun
lokal via [Auth API](/auth-api): `POST {SSO}/api/auth/bind` (`name`, `email`,
`client_id`, `return_url`) → tampilkan `data.url` ke user → setelah redirect
`{return_url}?bind_token=<JWT>`, verifikasi RS256 via JWKS (`iss`, `aud` =
client_id sendiri, `event = account.bind`, `exp` ±5 mnt) → tautkan akun lokal.
Sinkronisasi via `GET {SSO}/api/auth/binding/status` **hanya** untuk akun
ter-bind lokal.

Sejak update terbaru, submit form/konfirmasi **tidak langsung** mengeksekusi
bind — SSO menyimpan niat bind + mengirim kode OTP 6 digit
(`purpose = bind_account`) ke email user, lalu redirect ke
`/api/auth/bind/otp?token=<PENDING>`. Bind dieksekusi dan `bind_token`
di-redirect ke `return_url` hanya setelah OTP benar (bisa kirim ulang via
`resend=1`). `DummyWebSSO` belum mendukung langkah OTP ini — lihat alur
lengkap di [Auth API — Bind](/auth-api).

## Auth API & Avatar

Lihat **[Auth API — Bind](/auth-api)**. Upload avatar via API
(`POST /api/avatar`) sudah **dihapus** — user mengganti foto lewat
[Portal Akun](/account-portal) (`POST /account/avatar`); aplikasimu cukup
membaca `avatar_url` terbaru dari `/userinfo` (contoh `userinfo()` di atas).
