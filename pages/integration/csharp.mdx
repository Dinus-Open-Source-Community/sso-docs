# Integrasi C# (.NET)

Contoh berikut memakai `HttpClient` bawaan .NET (ASP.NET Core minimal API) —
tanpa package tambahan. Pola yang sama berlaku untuk Blazor, MVC, atau worker.

## Setup

```csharp
// SsoOptions.cs
public static class SsoOptions
{
    public const string BaseUrl       = "https://sso.doscom.org";
    public static string ClientId     => Environment.GetEnvironmentVariable("SSO_CLIENT_ID")!;
    public static string ClientSecret => Environment.GetEnvironmentVariable("SSO_CLIENT_SECRET") ?? "";
    public static string RedirectUri  => "https://appkamu.com/callback";

    public static readonly HttpClient Http = new HttpClient();
}
```

## Handler Login

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Web;

// Bangkitkan PKCE (S256) + state, simpan di session/cookie, lalu redirect
public static string AuthorizeUrl(string state, string codeVerifier)
{
    // code_challenge = BASE64URL(SHA256(code_verifier))
    var digest = SHA256.HashData(Encoding.ASCII.GetBytes(codeVerifier));
    var challenge = Convert.ToBase64String(digest)
        .TrimEnd('=').Replace('+', '-').Replace('/', '_');

    var q = new Dictionary<string, string>
    {
        ["client_id"]             = SsoOptions.ClientId,
        ["redirect_uri"]          = SsoOptions.RedirectUri,
        ["response_type"]         = "code",
        ["scope"]                 = "openid profile email",
        ["state"]                 = state,
        ["code_challenge"]        = challenge,
        ["code_challenge_method"] = "S256",
    };
    var qs = string.Join("&", q.Select(kv =>
        $"{HttpUtility.UrlEncode(kv.Key)}={HttpUtility.UrlEncode(kv.Value)}"));

    return $"{SsoOptions.BaseUrl}/authorize?{qs}";
}

// Helper: token acak untuk state / verifier
public static string RandomToken()
{
    var bytes = RandomNumberGenerator.GetBytes(32);
    return Convert.ToBase64String(bytes).TrimEnd('=').Replace('+', '-').Replace('/', '_');
}
```

## Handler Callback — Tukar Code

```csharp
using System.Net.Http.Json;
using System.Text.Json;

public record TokenResponse(
    [property: JsonPropertyName("access_token")]  string AccessToken,
    [property: JsonPropertyName("token_type")]    string TokenType,
    [property: JsonPropertyName("expires_in")]    int ExpiresIn,
    [property: JsonPropertyName("refresh_token")] string? RefreshToken,
    [property: JsonPropertyName("id_token")]      string? IdToken,
    [property: JsonPropertyName("scope")]         string? Scope
);

public static async Task<TokenResponse> ExchangeAsync(string code, string codeVerifier)
{
    // 1. Verifikasi state dari query terhadap state yang disimpan (CSRF)!

    // 2. Tukar code → token
    var form = new Dictionary<string, string>
    {
        ["grant_type"]    = "authorization_code",
        ["code"]          = code,
        ["redirect_uri"]  = SsoOptions.RedirectUri,
        ["client_id"]     = SsoOptions.ClientId,
        ["code_verifier"] = codeVerifier, // kosongkan untuk confidential tanpa PKCE
    };
    if (SsoOptions.ClientSecret != "")
        form["client_secret"] = SsoOptions.ClientSecret;

    var resp = await SsoOptions.Http.PostAsync(
        $"{SsoOptions.BaseUrl}/token",
        new FormUrlEncodedContent(form));

    resp.EnsureSuccessStatusCode();
    return (await resp.Content.ReadFromJsonAsync<TokenResponse>())!;
}
```

## Ambil Profil dari /userinfo

```csharp
public static async Task<JsonElement> UserinfoAsync(string accessToken)
{
    using var req = new HttpRequestMessage(HttpMethod.Get,
        $"{SsoOptions.BaseUrl}/userinfo");
    req.Headers.Authorization = new("Bearer", accessToken);

    var resp = await SsoOptions.Http.SendAsync(req);
    resp.EnsureSuccessStatusCode();
    return await resp.Content.ReadFromJsonAsync<JsonElement>();
    // id, name, email, avatar_url, bind, email_verified, created_at
    // (bind = [{client_id, name}], otomatis terisi saat login sukses)
}
```

<Callout type="info">
  Verifikasi `id_token` secara lokal: unduh JWKS dari `/.well-known/jwks.json` dan
  verifikasi signature RS256 dengan `System.IdentityModel.Tokens.Jwt`
  (`JwtSecurityTokenHandler` + `JsonWebKeySet`). Cek `iss` = base URL SSO,
  `aud` = client_id, `exp`.
</Callout>

## Bind Akun & Status Bind

Pola acuan: `DummyWebSSO` (`sso.js`). Selain "Login with Doscom", tautkan akun
lokal via [Auth API](/auth-api): `POST {SSO}/api/auth/bind` (`name`, `email`,
`client_id`, `return_url`) → tampilkan `data.url` → setelah redirect
`{return_url}?bind_token=<JWT>`, verifikasi RS256 via JWKS (`iss`, `aud` =
client_id sendiri, `event = account.bind`, `exp` ±5 mnt). Sinkronisasi via
`GET {SSO}/api/auth/binding/status` **hanya** untuk akun ter-bind lokal.

Sejak update terbaru, submit form/konfirmasi **tidak langsung** mengeksekusi
bind — SSO menyimpan niat bind + mengirim kode OTP 6 digit
(`purpose = bind_account`) ke email user, lalu redirect ke
`/api/auth/bind/otp?token=<PENDING>`. Bind dieksekusi dan `bind_token`
di-redirect ke `return_url` hanya setelah OTP benar (bisa kirim ulang via
`resend=1`). `DummyWebSSO` belum mendukung langkah OTP ini — lihat alur
lengkap di [Auth API — Bind](/auth-api).

Lihat **[Auth API — Bind](/auth-api)**. Upload avatar via API
